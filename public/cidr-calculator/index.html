What is CIDR notation?

CIDR (Classless Inter-Domain Routing) writes an IP address followed by a slash and a prefix length, such as 192.168.1.0/24. The prefix length is the number of leading bits that identify the network; the remaining bits identify hosts inside it. A /24 in IPv4 has 8 host bits, giving 256 addresses.

Usable hosts in a subnet

In IPv4, the first address is the network address and the last is the broadcast address, so a subnet has 2n − 2 usable hosts. The exceptions are /31 point-to-point links (2 usable hosts, RFC 3021) and /32 single-host routes (1 address). IPv6 has no broadcast address, so every address in the block is usable.

What is a wildcard mask?

A wildcard mask is the bitwise inverse of the subnet mask. It is commonly used in access control lists and routing protocols such as OSPF. For a /24, the subnet mask is 255.255.255.0 and the wildcard mask is 0.0.0.255.
