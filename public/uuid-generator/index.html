UUID Generator

This free online UUID generator creates universally unique identifiers (also called GUIDs) directly in your browser using the Web Crypto random number generator. Generate up to 1,000 at a time, format them as you need, and inspect any UUID to see its version, variant and embedded timestamp. Nothing is sent to a server.

Which UUID version should I use?

  • v4 — 122 random bits. The common default for request IDs, tokens and primary keys when ordering does not matter.
  • v7 — starts with a Unix millisecond timestamp, so values sort by creation time. Better than v4 for database primary keys because inserts stay index-friendly.
  • v1 — a 100-nanosecond timestamp plus a node ID. This tool uses a random node ID rather than your MAC address, so it does not reveal your hardware.
  • v5 — a SHA-1 hash of a namespace and a name. The same inputs always give the same UUID, which makes it useful for stable, reproducible identifiers.
  • Nil and Max — the special all-zero and all-one UUIDs, often used as placeholders.

Are UUIDs unique and secure?

Random UUIDs are unique in practice: the chance of a v4 collision is negligible. But a UUID is an identifier, not a secret. Do not use v1, v5 or v7 as passwords or access tokens, since they contain predictable parts. For secrets, use a dedicated random token of sufficient length.

How to use the UUID generator

  1. Choose a version and how many UUIDs you want.
  2. Pick a format: Uppercase, No hyphens or Braces, e.g. {550E8400-…} for .NET.
  3. Click Generate, then Copy all.
