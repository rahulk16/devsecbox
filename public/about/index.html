About DevSecBox

Built by Rahul Kumar

DevSecBox is a free collection of small, focused tools for developers and security engineers — things like Base64 encoding, JWT decoding, and JSON formatting that come up constantly in day-to-day engineering work but don't deserve a heavyweight app.

Why it exists

Most "online tool" sites are cluttered, slow, or send your data to a server you can't see. DevSecBox tools run entirely in your browser — nothing you type or paste is uploaded anywhere — and are built to load fast and get out of your way.

Who's behind it

DevSecBox is built and maintained by Rahul Kumar, a developer building tools out of everyday engineering needs. The project is open source — you can view the code, suggest tools, or report issues on GitHub.

What's next

New tools are added over time — see the homepage for what's live and what's coming soon. Have a tool you'd like to see? Reach out via the contact page.
