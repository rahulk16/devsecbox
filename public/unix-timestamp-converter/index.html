Unix Timestamp Converter

This free online Unix timestamp converter turns epoch time into a human-readable date and turns a date back into a Unix timestamp. It shows the result in UTC, ISO 8601 and any timezone you choose, and everything is calculated in your browser — nothing is sent to a server.

What is a Unix timestamp?

A Unix timestamp (also called epoch time or POSIX time) is the number of seconds that have elapsed since 1 January 1970 00:00:00 UTC, not counting leap seconds. It is a compact, timezone-independent way to store and compare moments in time, and is used in databases, logs, APIs and JSON Web Tokens.

Seconds, milliseconds, microseconds or nanoseconds?

Many systems use different units: classic Unix time and JWT claims use seconds (10 digits today), JavaScript and Java use milliseconds (13 digits), and some databases and tracing tools use microseconds or nanoseconds. With Auto-detect the converter picks the unit from the size of the number. Values below 100,000,000,000 are read as seconds, so a millisecond timestamp from before March 1973 needs the unit chosen manually.

How to convert a date to a Unix timestamp

  1. Pick the timezone the date is expressed in.
  2. Enter a date such as 2026-11-14 16:30:00, or an ISO 8601 value like 2026-11-14T16:30:00Z.
  3. Read the Unix time in seconds and milliseconds. A trailing Z or offset such as +05:30 in the input overrides the selected timezone.

What is the Year 2038 problem?

Systems that store Unix time as a signed 32-bit integer overflow at 03:14:07 UTC on 19 January 2038 (timestamp 2147483647). Modern 64-bit systems are not affected. Use the 2147483647 example above to see the exact moment.
