URL Encoder and Decoder

This free online URL encoder and decoder converts text to and from percent-encoding (also called URL encoding). Special characters become a % followed by two hex digits, using UTF-8 for non-ASCII text, so the result is safe to put in a URL. Everything is processed in your browser and nothing is uploaded.

What is URL encoding?

URLs can only contain a limited set of ASCII characters. Anything else — spaces, quotes, accents, emoji, or characters that have a special meaning such as &, = and # — has to be percent-encoded. A space becomes %20 and é becomes %C3%A9.

Component or full URL?

  • Component encodes everything except letters, digits and - _ . ! ~ * ' ( ). Use it for a single query value or path segment. It matches JavaScript's encodeURIComponent.
  • Full URL leaves characters that structure a URL (: / ? # & = @ and similar) alone, so an entire address stays usable. It matches encodeURI.

Plus sign or %20 for spaces?

In query strings sent as HTML forms (application/x-www-form-urlencoded), a space is written as +. Everywhere else, including URL paths, it must be %20. Turn on Space as + when encoding form data, and when decoding a query string that uses + for spaces.

How to use the URL encoder and decoder

  1. Choose Encode or Decode.
  2. Pick a scope and any options that fit your use case.
  3. Enter your text or URL; the result updates as you type.
  4. Click Copy, or Swap to feed the result back in the opposite direction.

Why does decoding say a sequence is malformed?

A % must be followed by two hex digits, and the bytes must form valid UTF-8. When that is not the case, the tool decodes what it can, leaves the rest unchanged and tells you. Text that is still encoded after one pass was probably encoded twice; run it through again to fully decode it.
